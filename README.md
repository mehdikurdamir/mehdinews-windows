# MehdiNews برای ویندوز

**MehdiNews** یک برنامه‌ی دسکتاپ ویندوز است که اخبار فناوری فارسی را از چند سایت خبری جمع می‌کند، به‌صورت خودکار دسته‌بندی می‌کند و در یک رابط کاملاً فارسی و راست‌به‌چپ نشان می‌دهد. فونت **وزیر** داخل خود برنامه قرار دارد و نیازی به نصب جداگانه ندارد.

> English: MehdiNews is a Persian-language (RTL) tech news reader for Windows, built with Electron. It aggregates RSS feeds, auto-categorizes articles, and ships with the Vazir font embedded. An Android version lives in a separate repository (`mehdinews-android`).

## امکانات

- دریافت اخبار از RSS: زومیت، دیجیاتو، دیجی‌کالا مگ، گجت‌نیوز، آی‌تی‌ایران و ترفندستان
- دسته‌بندی خودکار: هوش مصنوعی، موبایل و تبلت، سخت‌افزار، نرم‌افزار و سیستم‌عامل، بازی، امنیت، اینترنت و شبکه‌های اجتماعی، گجت، خودرو، علم و فضا، کسب‌وکار، ارز دیجیتال و سایر
- چیدمان بر اساس روز، جستجو، فیلتر منبع و ذخیره‌ی خبر برای بعد
- تم روشن و تیره
- به‌روزرسانی خودکار (پیش‌فرض هر ۲۰ دقیقه) و نگه‌داشتن آخرین اخبار برای حالت آفلاین
- افزودن و حذف منبع RSS دلخواه از بخش «منابع و تنظیمات»
- نصب‌کننده‌ی فارسی که بدون دسترسی ادمین نصب می‌شود

## اجرا از روی کد

به Node.js (نسخه‌ی ۱۸ یا بالاتر) نیاز دارید.

```bash
npm install
npm start
```

## ساخت فایل نصب (Installer)

روی ویندوز:

```bash
npm run dist
```

خروجی در پوشه‌ی `dist/` قرار می‌گیرد (`MehdiNews-Setup-<version>.exe`).

اگر روی لینوکس هستید و Wine ندارید، می‌توانید برنامه‌ی بسته‌بندی‌شده را با `npx electron-builder --win dir --x64` بسازید و سپس با `makensis installer.nsi` نصب‌کننده را کامپایل کنید (فایل `installer.nsi` همین کار را می‌کند و به پوشه‌ی `dist/win-unpacked` اشاره دارد).

## ساختار پروژه

| مسیر | توضیح |
|---|---|
| `src/main.js` | پروسه‌ی اصلی Electron: دریافت فیدها، پارس RSS/Atom، ذخیره‌ی کش و تنظیمات |
| `src/classify.js` | دسته‌بندی بر اساس کلیدواژه (اضافه کردن کلمه یا دسته در همین فایل) |
| `src/preload.js` | پل امن بین رابط و پروسه‌ی اصلی |
| `src/index.html`, `style.css`, `app.js` | رابط کاربری |
| `src/fonts/` | فونت وزیر (مجوز OFL) |
| `installer.nsi` | اسکریپت جایگزین NSIS برای ساخت نصب‌کننده روی لینوکس |

## محدودیت‌ها

- دسته‌بندی بر پایه‌ی کلیدواژه است و گاهی خبری را در دسته‌ی نامناسب می‌گذارد.
- آدرس فیدها ممکن است در طول زمان تغییر کند؛ منبع ناسالم رد می‌شود و بقیه کار می‌کنند. آدرس‌ها در `DEFAULT_SOURCES` داخل `src/main.js` هستند.
- فایل نصب امضای دیجیتال ندارد، پس ویندوز ممکن است هشدار SmartScreen نشان دهد.
